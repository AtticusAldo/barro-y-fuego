# Barro y Fuego

Pre-entrega del proyecto del curso de Front-End (Clase 08).

Sitio web de una tienda ficticia de cerámica artesanal. Muestra los productos, reseñas de clientes y un formulario de contacto.

## Tecnologías
- HTML5 semántico (header, nav, main, section, footer)
- CSS3 (Flexbox, Grid y Media Queries)
- Google Fonts (Caveat y Nunito)
- Formspree para el formulario de contacto
